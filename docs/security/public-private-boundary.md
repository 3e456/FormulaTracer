# Public/private boundary

FormulaTracer is distributed as a generic scientific-program audit library. Its
repository and packages must not be used as storage for user research.

## Public

- FormulaTracer source, native semantic core, stable schemas, and bindings;
- independently authored generic tests and synthetic examples;
- public OSS and official mathematical-reference metadata;
- self-generated, mutation, metamorphic, and finite-domain assurance;
- bucketed aggregate statements about private-scale operational exercise; and
- public security, trust-boundary, license, and citation documentation.

## Private

- user theories and research-specific formulas;
- research source, data, datasets, model names, and system boundaries;
- local paths, environment inventories, and account or machine metadata;
- detailed operational audit results, certificates, source spans, and maps;
- research-specific provenance, lineage, output names, and values; and
- secrets, credentials, private URLs, and private repository metadata.

Private audit input and output belong beside the private project or in another
access-controlled location. They must not be copied into FormulaTracer. Public
reproductions must be independently constructed rather than created by literal
renaming or coefficient substitution.

Release packaging and repository scans enforce this boundary with redacted
fingerprints: reports record categories and counts, not matched private text.
