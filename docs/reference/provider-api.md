# Provider Contract Reference

`output/public_function_reference/provider-reference.json` is the searchable
index. Each item identifies its registry source and version policy. Entries are
selected contracts or references; the catalog size is **not** a supported
function count and does not promise an entire upstream library.

NumPy, SciPy, pandas, xarray, and Dask examples retain dtype, axis, shape,
labels/alignment, backend, reduction-tree, and provider-error limitations where
applicable. Missing provider or runtime facts produce partial/unresolved
results. Provider documentation is reference evidence, not Lean proof.
