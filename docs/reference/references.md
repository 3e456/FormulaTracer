# References and evidence provenance

References provide definitions, contracts, standards, and validation context;
similarity to a reference is not a correctness proof. Machine-readable records
are in `output/public_docs/reference-inventory.json`.

Principal official sources used by public contracts include the NumPy, SciPy,
xarray, pandas, Dask, JAX, PyTorch, and CuPy API references; Python, Rust, C++,
LLVM/Clang, and IEEE specifications; Lean/mathlib documentation; BLAS/LAPACK
references; NIST DLMF; Boost.Math documentation; and the Apache License text.

Each record identifies the organization or author, title/version, official URL
or DOI, FormulaTracer concept, access date, and whether any source was retained
or copied. Public release validation retains URLs, revisions, semantic
fingerprints, and results—not external source trees or long copied excerpts.
