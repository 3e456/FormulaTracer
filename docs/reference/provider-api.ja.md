# Provider Contractリファレンス

検索可能なindexは`output/public_function_reference/provider-reference.json`です。
各項目はregistry sourceとversion policyを保持します。entryは選択contract/referenceであり、
catalog件数はsupported function数でもupstream library全体の保証でもありません。

NumPy、SciPy、pandas、xarray、Daskの例では、必要に応じdtype、axis、shape、
label/alignment、backend、reduction tree、provider errorの制約を保持します。
provider/runtime情報が不足すればpartial/unresolvedです。provider documentはreference evidenceでありLean proofではありません。
